# Changelog

## 0.1.0

- First release: `new GaiaDesk({ apiKey })` with `support.sessions` (create, list, get, update,
  end, attachments), `support.alerts`, `support.listeners`, `support.requests`, `webhooks`
  (create, list, delete) and `webhooks.verify`. Types generated from GaiaDesk's OpenAPI document.
